# Extension Icons

Placeholder: Add actual icon images here (16x16, 48x48, 128x128 PNG files).

For now, the extension will use default browser icons.

To create icons:
1. Design a logo representing "snub.io" / noise filtering
2. Export as PNG at 16px, 48px, and 128px sizes
3. Name as `icon-16.png`, `icon-48.png`, `icon-128.png`
4. Place in this directory

Suggested design:
- Cyberpunk aesthetic (neon cyan/pink)
- Symbol: 🤫 or crossed-out megaphone
- Monospace font for any text
